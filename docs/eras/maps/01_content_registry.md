# Map 01: content layer, era coupling and the era registry (read-only survey, 2026-10-08)

Everything below was measured on the working tree (node introspection of the real modules, grep, esbuild size runs), not copied from docs. Paths are relative to /home/user/voxelwars. "Ancient" = `src/content/era_ancient/`.

## 1. What this subsystem does today

1. `src/content/` contains exactly ONE directory, `era_ancient/` (77 files, 14,015 lines, 946,500 B of source). There is no `src/content/index.js`, no era registry and no `era` field on any def, faction, arena, prop or part. `grep era_ancient` hits 121 files under src/tools/tests (section 2.4); 2 more are generated.
2. Numeric truth is `era_ancient/stats.js` (81 lines): `STAT_TABLE` = 43 units (one object literal per line, built with local helpers `M()` melee, `R()` ranged, `S()` shield that are NOT exported), `FACTIONS` = 7 `{name, blurb, colors:[hex,hex]}`, `DEFAULTS` = 7 keys (radius .55, mass 1, turnRate 9, accel 14, runMul 1.5, scale 1, kb 4). Roles in use: melee 10, ranged 7, cavalry 6, hero 6, support 4, monster 4, siege 3, beast 2, swarm 1. Factions: hellenes 7, romans 7, egyptians 8, persians 5, carthage 4, barbarians 5, mythic 7.
3. `src/sim/defs.js buildSimDefs(extra)` is the single choke point that turns a table into defs: loops `STAT_TABLE`, `normalizeDef` (fixed 27-key `TOP_KEYS` order for monomorphic hot loops, sub-objects `melee/ranged/shield/ai` likewise), then overlays `extra[id]={model,text,name}`. 22 files reference it (the definition + 21 callers: content.js and ui/mockctx.js pass `extra`; survival.js, daily.js, armygen `defsOr`, tools/mixtest.mjs, tools/lib/harness.mjs and 14 tests call it bare).
4. `era_ancient/content.js buildContent()` (79 lines, COORD) = glue: `collect()` merges `MODELS` (units/*), `BUILDERS` (beasts/*), `UNIT_TEXT` (humor/*) from the generated registry with `Object.assign` (a duplicate id silently overrides, last alphabetical module wins), calls `buildSimDefs(extra)`, fills a prettified `name` if missing, and exposes `modelFor(def, unit)` with a per-id cache, riders/crews from an inline `CREWS` table (content.js:39) plus the `rider_<id>` blueprint naming convention.
5. Models: 28 humanoid units are `{kind:'humanoid', blueprint}` specs compiled lazily by `blueprints.js compileSoldier` (injected by `setCompiler`, called in app/main.js:45); 15 non-humanoids have `model:null` and resolve through `beasts/index.js BUILDERS[unitId]` (BUILDER_KIND: mounted 6, beast 4, bespoke 5); anything else gets `fallback_model.js` (hum1 or quad1 block model in faction colours). Model max 48 parts (contracts.mjs enforces).
6. Text: `humor/units_text.js UNIT_TEXT` (728 lines, 43 entries `{name, plural, blurb<=14w, lore<=35w, deaths[3], taunts[2], codexJoke, proper?, <moment keys>}`) is merged into each def as `def.text`. All other text is imported by module path, not through the content object: announcer (1,198 lines), achievements, killverbs, results_text, names, tips, ui_text, credits, scout_text, barks.
7. Parts: global singleton `PART_REGISTRY` in `parts/_registry.js` (12 categories); 254 parts registered after all modules load (helms 55, hair 13, faces 15, tunics 22, armors 18, shoulders 12, legs 13, skirts 3, capes 9, backs 14, mains 56, offs 24); 172 come from `blueprints.js` static side-effect imports, 82 from `units_*` parts imported by `units/*.js`. `registerParts` THROWS on a duplicate id with a different object (import-time failure). 12 parts are locked behind `UNLOCKS` (silly_helms, silly_weapons, wings).
8. Props: `props/catalog.js PROP_CATALOG` (41 ids: nature 15, props 11, architecture 7, monuments 8; fields cat,r,h,hp,blocks,cover,flam,place,scale,name) + `props/models/index.js` (5 model modules merged by `Object.assign`; `buildProp(type,stage,variant)`). Arenas: `arenas.js ARENAS` (16 presets: id,name,recipe,size,seed,theme,mood,recommendedBudget,blurb,tactics) whose `recipe` names a generator in `src/world/gen.js` (private `const R`, `RECIPES=Object.keys(R)`, 16 materials in world/arena.js).
9. Mode data (all Ancient-only, loaded via `_generated/registry.optional.js`): `campaign.js` (9 missions, 3 acts, `campaignApi`, `MUTATOR_STARS`), `campaign_run.js` (engine: MissionRuntime, MissionTracker, ScriptedWaves), `campaign_validate.js`, `campaign_text.js`, `puzzles.js` (6) + `puzzle_solutions.js`, `survival.js`, `daily.js`, `custom.js` (custom soldier glue), `lesson_text.js`, `wave_names.js`, `sim_text.js`.
10. The sim reads content statically in 6 files / 7 import lines: defs.js and stats.js (STAT_TABLE, DEFAULTS), unit.js (DEFAULTS), world.js (propInfo, SIM_BARKS), lessons.js (LESSON_TEXT), waves.js (WAVE_NAMES, BOSS_NAMES, BOSS_CYCLE). `World` itself is defs-INJECTED (`new World({arena, seed, rules, defs})`), so battles already run on whatever defs map they are given. tools/lint.mjs has NO rule against sim importing content (10 rules: pure-dom, pure-three, math-random for sim+content, import-three, dialogs, eval, innerHTML, location-search, abs-fetch, dilution).
11. Registry generation: `tools/gen-registry.mjs` (53 lines) globs HARD-CODED `src/content/era_ancient/{units,parts,beasts,props/models,humor}` (+ `src/anim/clips`, `src/sim/abilities`) into `src/_generated/registry.content.js` (209 lines) and 9 ancient single-module paths (BLUEPRINTS, PROP_BUILDERS, CAMPAIGN, ANNOUNCER, UI_TEXT, CUSTOM, SURVIVAL, PUZZLES, DAILY) + 17 others into `registry.optional.js`. Only UNIT_MODEL/PART/BEAST/HUMOR are consumed (content.js:6); PROP_MODEL_MODULES, CLIP_MODULES, ABILITY_MODULES are generated but have no consumer.
12. Sizes: `registry.content.js` minified = 555,333 B; whole app bundle minified 1,874,886 B; packed `dist/artifact/index.html` = 3,106,540 B against the 5 MB budget (e.md); CSP allows scripts only from cdnjs/jsDelivr/unpkg (spec.md:357), so all eras must ship inside the one inline bundle.
13. Gate pins to Ancient counts: 43 units (tools/contracts.mjs:49, tests/humor/text.test.mjs:26,40, tests/sim/armygen.test.mjs:81, tests/ui/ui5_flows_slow.test.mjs:245 "43 units across 7 faction tabs"), 41 props + `LIMITS.propTypes===41` (tests/editors/arena/entry.test.mjs:26), 16 materials (:20), 24 achievements (humor/text.test.mjs:75, save/stats.test.mjs:197), 9 missions, 16 arenas (ui5_flows_slow:257), BOSS_CYCLE literal (campaign/survival.test.mjs:34), 9 mutators, 9 scout codes.
