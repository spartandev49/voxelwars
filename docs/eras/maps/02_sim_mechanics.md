# 02 Sim mechanics map: `src/sim/**` (deterministic 30 Hz core, SIM owns it)

Read-only survey, 2026-10-08. Everything below was read in the code or measured on this box (thread CPU, `tools/perf_sim.mjs`, scratch micro-benchmarks outside the repo). Items I could not confirm are in section 7. Paths are relative to `/home/user/voxelwars`. `src/world/**` (nav, arena) is COORD-owned, `src/content/**` is split (stats.js + props/catalog.js are SIM's).

## 1. What the sim does today (facts)
- **Tick** (`world.js:444 tick()`): drain tick-stamped inputs -> hash rebuild (cell 3 u) -> flow fields (one team per 6 ticks, so each field refreshes every 12) -> `_updateStatusesAndMods` -> `updateSquads` -> waves, hazards, godpowers, possession, mutators -> per unit: cooldowns, `think` (AI), `_tickAbilities` -> `_integrate` per unit -> `_separate` (2 passes) -> `proj.update` -> effects, props burning -> morale -> reap/dying -> `_checkEnd` -> objective. DT = 1/30. Teams 0/1 only (`TEAM_N` exists, unused). Stats slot 2 is legacy.
- **Space**: ground plane only. `u.y` follows `arena.cellHeight` (rise <= 12 u/s `G.groundFollow`, falls under `G.gravity` 22). `Unit.altitude` exists and is read by nothing. `ST.FLY` means "knocked airborne" (geyser, dash), NOT a flying unit. There are no layers, no flyers, no vehicles; mounts, riders and crews are cosmetic (`def.model`), the sim sees ONE body (`radius, mass, height, hp`) with tags (`cavalry`, `large`, `animal`).
- **Weapon model** (`defs.js SUB`): `melee {dmg, cd, range, type, style, kb, ap}` (`cleave` is declared but never read), `ranged {proj, dmg, cd, range, type, ap, speed, spread, gravity, pierceN, minRange, whileMoving, aoe, volley, crater, chain, kb}`, `shield {arc, block, proj}`. A unit may have melee AND ranged (elephant, chariot, cyclops). `range` = edge gap. `cd` = full cycle; clip rate clamped 1..2.4 so a cycle can never be shorter than `clipDur/2.4`.
- **Damage** (`combat.js:87 applyDamage`, the only entry; `dotDamage` bypasses it): `raw = base*rand(0.9,1.1)`; shield block (front arc, not for aoe/dot, rolls `block` or `proj`); crit 6% x2; melee backstab x1.35 (outside 120 deg arc); charge x(1+chargeMul); `src.mDmg`, mutator, `dst.mDmgTaken`; fire x`fire_weak` x weather; sleep x1.5; stone+blunt x2; `eff = clamp((armor+mArmor)*(1-ap),0,0.9)`; `fin = max(1, raw*(1-eff))` (1 damage floor); knockback `kb*dmg/mass*0.06`; hooks `onHitDealt/onDamaged/onLethal`. Types: `slash pierce blunt fire magic`, AP table `{slash 0, pierce .3, blunt .2, fire 1, magic 1}` (`consts.js:19-20`). One scalar armour, no per-type resist, no facing armour, no regenerating pool.
- **Projectiles** (`projectiles.js`, 162 lines): pooled (600, grows to hard max 4000, `fire()` returns null beyond). Kinds in data: `arrow javelin pilum francisca boulder bolt coin sunbeam scepter thunderbolt` (+ runtime `crew`). Ballistic low-arc solver (45 deg fallback), 2-iteration target lead (only when `gravity>0` and kind != bolt), gaussian spread, sub-steps <= 0.7 u, hits first unit cylinder (y-aware: `p.y` vs `u.y..u.y+height`), blocked by terrain and `cover` props (3D height test), `pierceN` (x0.8), `aoe` falloff 1->0.4 via `world.areaDamage`, `crater` -> `makeCrater`. No homing, no hitscan, no bursts; `sunbeam/thunderbolt` are just fast (60-80 u/s) straight bolts. Boulders only hit on the way down.
- **Statuses**: 20 float slots `SE` (`BURN SLOW STUN ROOT CONFUSE SLEEP STONE RAGE HASTE DMGUP CURSE SCARE TIPSY POISON DISARM TAUNT PANIC DOWNED WARHORN NOHEAL`; WARHORN and NOHEAL are never set). Names derive from `Object.keys(SE)`; render `battleview.js statusMode` hard-codes indices 0 and 13, so slots are append-only.
- **Abilities**: DATA-parameterised CODE. `def.abilities = [{id, ...params}]`, code registered by `reg(id, impl)` in 27 files (`abilities/index.js` imports them; registry has 27 ids). Hooks: `init tick mods onAim onFire onHitDealt onBlocked onBlock onDamaged onLethal onKilled onKill onLand onBurn cast`. Shared helpers `abilities/util.js` (`collect`, `beginChannel/tickChannel`, `emitTelegraph`, `chainLightning`). Easy AI does not cast except heroes (`aiAllowed`).
- **AI** (`ai.js`, 477 lines; `squads.js` 197): 3 layers (squad anchor + formation slots + flow field; tactical `pickTarget` scored target + hysteresis + engagement slots; movement/steer/separate). `pickTarget` runs every 12 ticks (6 hard, 24 easy), skips units whose field distance > scan*1.7+6. Ranged units stand at 0.85 x range, kite at gap < 5.2 only when the def has a melee side-arm AND is tagged `skirmisher` or style `skirmish` (normal and hard; inside `minRange` every difficulty backs off), fire only if `|heading-want|<0.4`. NO line of sight, NO cover seeking, NO fog; ranged shots into walls just stick. Cavalry prefer ranged/siege/support (+40), spears prefer cavalry (+24), `ai.preferTargets` tags (+20) is implemented but no shipped unit sets it.
- **Siege**: props are circles `{r,h,hp,blocks,cover,flam}` (`props/catalog.js`, 41 types). hp finite => `nav.soft` (path cost +30, solid until destroyed), else `nav.block`. Blocked squads/units become breachers (`ai.js:254`): melee dmg x(blunt 1.5, slash 1, pierce .7) x(mass>=6 ? 2 : 1) via `hurtProp`; siege ranged engines shell the prop. `gate_door` r2.2 hp 700, `wall_stone` r1 hp 600 (a wall is a chain of props), `tower` r1.6 h9 hp 900 (obstacle only). Non-aoe projectiles do NOT damage props; aoe does `damageProps(r, dmg*1.2)`. Props have no team: defenders breach their own gates. Terrain height is the only elevation (walkable step <= 1 u, cell spread <= 3 steps).
- **Hazards** (`hazards.js` 137): arena circles `{t,x,z,r}`: quicksand, spikes, fire, boulders, geyser (+ lava/deep water via `_liquid`). **Craters** (`world.js:187 makeCrater`): `arena.crater` bowl+rim, `nav.rebuild(rect)`, `nav.applyProps`, `invalidateFields()` (forces BOTH Dijkstras next tick). The World owns a CLONE of the arena.
- **Others**: objectives 7 (`eliminate kill_general hold_hill protect_vip survive_waves destroy timeout`), waves (budget 2400+900n, 6 styles, boss every 5th from `BOSS_CYCLE`), god powers 6 (hard-coded `GOD_POWERS`), mutators 9, morale/rout (`G.rout 15`, rally 40), stalemate watchdog (12/18/30/44 s: warning, advance, Zeus + goat, ragequit draw), possession, `stateHash` (id,x,z,hp,team per live unit + rng.s + tickN ONLY).
- **Determinism**: ONE RNG stream `world.rng` (mulberry32). Each hit draws 1-3 numbers, each shot with spread draws 6, `addUnit` draws 3 + 1 per ability. Barks use `(tickN,id)` hash rolls, no RNG. `Math.random` banned in `src/sim`+`src/content` by `tools/lint.mjs`.
- **Perf (measured now, thread CPU, warm JIT, marathon large, armygen mixed)**: 132u 0.53 ms, 308u 0.91 ms, 535u 1.41 ms per tick (budget 1.2/2/3 ms for 150/300/500; `docs/balance_report.md` 2026-10-06: 0.58/0.84/1.59/2.74 at 150/300/500/1000). Profile @308u: flow-field Dijkstra 29.7%, `_separate` 13.8%, `tick` 5.6%, `_integrate` 4.7%, `think` 3.5%, `pickTarget` 2.9%, `inFrontArc` 2.7%. Headroom at 300u is about 1.1 ms. Clock granularity is ~4 ms so per-tick p99/max are quantised: only averages mean something.
- **Coupling to Ancient**: 6 files, 7 import lines (section 3) + ancient unit ids hard-coded in 7 more places (section 3 'ids in code', `RIG_BY_ID`, `warmup.js` ROSTER). Everything else is data-driven through `world.defs`.

## 5. GAPS: can today's data model express it? (smallest new primitive, tick position, cost/unit/tick, determinism/perf risk)

## 6. RISKS (numbers)
- **Ancient drift (O4)**: ONE shared RNG. Any new draw executed in a path Ancient battles reach (hit, fire, addUnit) re-sequences every battle: `feasibility.json` (9 missions, bots counter/greedy n=20, turtle n=10, thrifty n=12, stamp `489eccc492`), `puzzle_solutions.js` (6 stored placements; `puzzles.test.mjs` fails if one stops winning), campaign star bands, `balance_report.md`. ANY edit under `src/sim`, `src/world` or `stats.js` changes `simHash` => feasibility replays print STALE (not fail) until `tests/campaign/run_feasibility.mjs` is re-run (~30 min per the CAMPAIGN note). Mitigation: draw nothing new unless the def carries a new-era field; give new mechanics their own `w.rng2 = rng.fork('era')`; leave Ancient `stats.js` numbers untouched.
- **stateHash blindness**: hashes only (id,x,z,hp,team)+rng+tick. Shield, ammo, cloak, suppress, aim, altitude are invisible to S1/S26 => extend the mix with every new state field (self-consistency tests only, no goldens, so safe).
- **Perf**: baseline 0.91 ms @308u vs 2 ms (headroom ~1.1 ms); Dijkstra = 30% (2.2 ms per field, 16,384 cells; a second ground-class/hover field would add ~0.37 ms/tick amortised). Budget proposal: all new per-unit systems together <= +0.5 ms @300u, +0.8 ms @500u. Estimates: shield regen 20 ns, turret 50 ns, cloak check 2 ns/candidate, suppression ~1 us/impact, hitscan ~60 us/shot, homing ~10 flops/substep. Craters: unthrottled forced refresh = 4.1 ms per crater tick (artillery at 4 craters/s = +0.55 ms/tick). Long-range weapons inflate `info.scan` (= range+3..6, sniper 60 => ~1,800 hash cells per scan per 12 ticks, ~23 us; 100 such units ~0.19 ms/tick); cap scan radius or use the field distance skip.
- **Buffers**: `qbuf2/3` 512 silently truncate: a 12 u EMP/orbital query in a packed blob (cell 3 u, 20+ units/cell) can exceed 512 => units silently unaffected; `qbuf` 1024 for scans. `areaDamage` + hook re-entrancy (seam 21).
- **NaN trap** (seam 12) and **unknown clip = idle timing** (seam 11) are silent failures; add contract checks (`tools/contracts.mjs`) for `type` in `AP`, `proj` in kind table, clip ids registered.
- **Hidden classes**: new def/unit keys outside `TOP_KEYS`/`SUB`/`Unit` constructor => megamorphic property loads in `think/_integrate/applyDamage` (perf cliff, not a bug).
- **Registry cap S16 = 32** (27 used, 5 free). Twelve new ids would need a spec amendment (propose 32 per era pack / 64 total) or the effect-param route (seam 26).
- **Termination (S11/S12/S23)**: untargetable-by-melee air units, cloak, regenerating shields vs low dps, infinite kiting snipers, and 2D-only range vs elevation can create battles nobody can finish; the watchdog ends them as 'intervention' (S11 still passes) but S12 median 60-120 s / p90 <= 180 s and S23 dead-air 0 will not.
- **Overlap/stuck metrics (S5/S8/S9)**: vehicles r 1.4-2.2 share the 1-cell nav (no radius inflation; elephants r1.5 already do), so gates/bridges < 3 cells clog; air/hover units overlap ground units in plan view and legitimately stand over water/lava.
- **Save compat**: custom soldiers store stats (`statsToUnitDef` re-derives, cost via `clampedCost`), armies store placements + def ids, share codes store rules+seed. Unit ids, ability ids, SE slot order, prop ids and hazard kinds are immutable; new rule fields must default.
- **Pre-existing bugs worth fixing in the same pass**: seam 21 `_tickEffects` buffer aliasing; `addPlacements` drops vip/general; `ProtectVip reachOnly` progress 0; ballista bolts do no wall damage; WARHORN/NOHEAL dead slots; `melee.cleave`, `Unit.altitude`, `landX/landZ`, `moraleBonus` dead fields.
