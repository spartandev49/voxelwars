# Map 07: audio, music, speech, humour layers and the asset pipeline (read-only survey, 2026-10-08)

Method: read `src/audio/*` (2,547 lines, 189,297 B source, 113,879 B minified in the bundle), grep of consumers, ran Node probes against the real modules, parsed `assets/manifest.json`, measured the page budget in memory with esbuild (nothing written to the repo), live HEAD/GET probes of source hosts and `tools/oga.py` against OpenGameArt. ## 1. What this subsystem does today
- **Engine** `src/audio/engine.js` (`AudioEngine`, 600 l): AudioContext made on the first gesture (`unlock.js installGate`); every method is a no-op before that. Graph: 5 buses (`music sfx ui announcer ambience`; per-bus duck gain + user volume) -> `masterIn` (preGain .631) -> compressor (thr -16, knee 10, ratio 5) -> limiter (thr -3, ratio 20) -> soft clip (ceil .84, 4x) -> master. 1.5 s generated reverb IR (return .45, 0 at Potato).
- **Voices** `voices.js VoiceManager`: budget 32 (24 Potato), 8 slots reserved for ambience loops; priority steal (heroes 90-100, near hits 50, far 10; priority x(0.2+0.8*near)); per-family `cooldownMs` + `maxVoices`; far sounds thinned when load > 0.65. **Spatial** `spatial.js`: rolloff 1/(1+(d/ref)^1.4), pan = lateral/25 x0.9, far low-pass 18 k -> 2.5 k, camera height weight .35 (max 40). **Ducking** `duck(bus, db, ms)` attack 20 ms: announcer lines -6 dB music 700 ms, horns -6/400, hero kill -3, battle end -9/2500.
- **Cues** `cues.js` (553 l): `CUES` = 116 families built by `F(id, tmpl, pick, opts)` from 16 templates (hit 13, ui 14, fx 13, beast 12, voice 10, amb 9, foley 9, destr 6, jingle 6, swing 4, crowd 4, siege 4, shoot 3, horn 3, drum 3, announce 3); 8 have `layers`. `pick` = selector union over the ledger: `id_prefix`, `#tag`, `@category`, `a&#b`, `!excl`; a list of GROUPS is tried in order (first group with a match wins). Variants through a shuffle bag, pitch jitter by `playbackRate`.
- **Router** `createRouter` (cues.js:~300-520): `H` = 43 handlers keyed by sim event type, fed by `bus.onAny` after `audio.attach(world.events, {arena, world, defs, getListener})` (`app/game.js:153`, `defs: this.content.defs` = merged defs, good). Not handled (no sound at all): `telegraph` (5 emit sites), `hazard_trigger` (4), `unit_rout`, `unit_stagger`, `possess`, `objective_update`, `wave_intermission`, `fire_started`, `unit_corpse_done`.
- **How a unit/weapon picks a sound** (all hard-coded in `H.*`): hit = payload `type` (slash/pierce/blunt) -> `hit_blade|pierce|blunt`, then armour clank with p = clamp(armor*1.1+.15, 0, .9) if `armor >= .1` else flesh light/heavy (heavy: dmg >= 22 or big or charge); swing = `melee.style`; `proj` hits only clank when `armor >= .3` (60%). Shot = `projectile_launch.kind` switch: boulder, bolt, javelin/pilum/francisca, coin, sunbeam/scepter/thunderbolt, **default `bow_shoot` (+`arrow_whoosh` 40%)**; impact = `projectile_hit` (boulder -> `boulder_impact`; blocked -> `arrow_hit_shield`; onUnit -> `arrow_hit_flesh`; arrow/bolt/javelin/pilum -> `arrow_hit_wood`). Kill = `unitProfile` (species from `SPECIES_BY_ID`, 12 ids + regex chicken/goat/hound/elephant; role, mass >= 6, scale >= 1.6, armor, tags) then a species ladder, else `CAUSE_SCREAM`/`death_oof` 15%/`death_male`. Ability = `ABILITY_CUES` (31 ancient ability ids). Explosion = `kind` fire/lightning/magic else `rubble`. Bark = id ladder philosopher/senator/chicken/goat else `taunt`. Foley bed (`tick`, 4 Hz): footsteps by `STEP_BY_BIOME` (8 biomes), `armor_rustle` for everyone, `elephant_step`/`horse_gallop` for big/mounted units.
- **Override hook that exists but is dead**: `UnitDef.sfx = {hit, swing, shoot, death, voice}` is read by `D(def, kind)` but no unit sets it (STAT_TABLE: 0 hits), `sfx` is not in `sim/defs.js TOP_KEYS`, and `projectile_launch` carries no `srcDef`, so `sfx.shoot` could never fire.
- **Synth fallback** `synth.js` (439 l): `RECIPES` = 116 (one per cue, asserted by tests), 22,050 Hz, 3 variants, deterministic (`mulberry32(hash(id)^v)`); served only when the ledger has no row, all rows failed, or a UI cue's file is still loading; non-UI cues are DROPPED (not synthesised) while a real file is merely loading. 8 synth-only families (`philosopher_mumble senator_blah crowd_boo wine_pour amb_birds amb_desert amb_forest amb_water`). Music fallback: `MUSIC_SPECS` 10 beds (menu editor victory defeat comedy + `battle_heroic|eastern|dark|mythic|brass`), `THEME_TO_SYNTH_BATTLE` maps 10 ancient themes.
- **Music** `music.js MusicDirector`: moods `menu editor battle victory defeat comedy`; `setMood(mood, {theme})`. Track = `rankTracks`: rows whose mood/tag matches; +3 if `themes` has the theme (NO row has `themes`), +1 per `THEME_STYLE[theme]` tag hit, +1.5/.75 for `THEME_ENERGY`; shuffle bag over rows within 2.0 of the best. With 8 rows (3 `battle_low|mid|high`) the theme only picks an energy tier. Battle-in-progress mood: `intensity` 0..1 (kill rate, attrition, hero bumps) -> low-pass 1.8-18 kHz and -6..0 dB, tau .5 s. Crossfade 1.5 s between moods, 3 s equal-power loop seam, one track decoded at a time (+prefetch of the next), a synth bed bridges slow fetches. `engine._comedyBattle()` -> mood `comedy` when >= 50% of units are `sacred_chicken`/`battle_goat` or mutators `chaos|chicken_rain`.
- **Ambience** `arenaInfo(arena)`: loops `amb_wind` always (+water/fire/crowd/birds/forest/desert by lava/water/props/biome/theme), thunder one-shots in storms; `colosseum` = name regex or >= 6 `crowd` props (drives crowd reactions).
- **Speech** `speech.js Speech`: optional Web Speech TTS, default OFF ("experimental"), 1 line per 6 s, priority >= 2, skipped above 2x speed, one global voice for all three commentators. Driven by `app/meta.js:476 M.speak(line)`. Three recorded-shout cues `announce_ready|go|winner` (setting `announcerVoice`, off).
- **Delivery**: ledger `assets/manifest.json` (374 sfx, 8 music, 35 vfx) is inlined as `window.__VW_MANIFEST__`; 27 sfx + 1 music flagged `core` are base64-embedded (`__VW_CORE_AUDIO__`); everything else is published beside the page (`dist/artifact/files.json` = `{published path: source}`, 382 entries) and fetched lazily with relative `fetch('assets/audio/...')` + `decodeAudioData`; `window.__VW_FILES__` (written by `tools/build.mjs`) makes `Catalog` skip unpublished rows (no 404s). States per asset: embedded | fetched | synth | failed (Diagnostics, `window.__vw.audio`).
- **Credits**: `assets/CREDITS.md` (generated by `tools/build_manifest.py`, 327 l, 18,387 B: 27 CC BY attribution lines + CC0 courtesy list, 124 list items) -> `window.__VW_CREDITS__` -> `ui/screens/credits.js` + `_md.js` (DOM-only markdown, filter box, entry/link chips). Studio jokes: `humor/credits_text.js` (16 roles, 3 footer lines) via `ui/strings.js:7`.

## 6. RISKS (numbers)
- **511-file version cap** (Artifact tool): 383 used, 128 free. Unpacked, three eras need ~418 audio files -> the publish fails or the last batches are rejected. Mitigations: sprite packs (about 6 groups x 3 eras = 18 files), drop the 15 unused ledger rows, or limit new sfx rows to <= 40 per era. Publishing 255 files per call also means 2+ calls for the unpacked case.
- **Page size** 3.11 MB / 5 MB. Estimates: per-era content code (non-audio) 562 KB minified in Ancient (humor 155, parts 135, top-level logic 126, beasts 68, props 61, units 17) x 0.348 deflate ratio = 196 KB x4/3 = 261 KB packed per era -> +0.78 MB for 3 eras at Ancient size; text alone about 140 KB min per era (units_text 650-800 B/unit, announcer 161-212 B/line, campaign 1.4-1.7 KB/mission) = about 60 KB packed per era. Manifest rows +1,000 -> +60 KB deflated unslimmed (+30 KB slimmed). New engine/anim/render code about +60 KB packed. **Projected 4.0-4.3 MB**; the single biggest lever is the 1.23 MB core music track (about 40% of the page). If a second `core` track per era were added the budget breaks (+3.7 MB).
- **Decoded PCM**: 63.2 MB now vs ceilings Potato 40 / Papyrus 80 / Marble 160 / Olympian 240 MB; `warm` decodes all rows of a group -> 4 eras = about 250 MB (over Marble and Olympian, 6x Potato) -> era-scoped warm is required; LRU eviction exists (`SfxBank._reserve`) but its thrash behaviour at 250 MB is not measured; a 123 s stereo track is 43 MB decoded (212 MB for all 8 tracks if all were resident; only current + next are).
- **Voice budget / perf**: `shoot` template: cooldown 35 ms, 8 voices; a 300-unit modern fight can emit hundreds of `projectile_launch` per second; each `unit_hit` calls up to 6 `play()`s. Guns need a `burst` template (cooldown 60-90 ms, maxVoices 5-6, `dur` cap .35 s, far cull 70 u), machine guns as short loops or 3-round samples, per-family stealing. Verified today only for ancient (`tests/audio/battle.test.mjs` 150v150 <= 32 voices; `mixtest` -18 +/- 3 LUFS); new loudness classes (explosions, lasers) must be re-run through `tools/mixtest.mjs`. Router runs on the main thread inside the render frame: budget not measured (event handlers allocate no objects except `play` opts).
- **Determinism**: audio lives outside the sim, uses its own `mulberry32(Math.random())` rng, never touches `stateHash`; sim barks are RNG-free (`world.bark` picks by `tickN*17+id*5`), so new text keys cannot re-sequence battles. Risk is only in SIM-side payload changes (`srcDef` on `projectile_launch`) which must not add RNG draws.
- **Save compat**: settings keys `vol.* muted tts announcerVoice` unchanged; achievement/mission/arena ids immutable (`save/migrate.js` imports `MISSION_IDS`); new eras need new ids only; custom soldier quotes/class labels (`custom_text`) are stored text, extend the label map, never rename.
- **Offline/AU4**: core pack covers ancient hits/UI/horns only; a modern battle with fetch blocked is silent for gunfire until the synth path (non-UI cues are dropped while a real file is merely 'loading', synth only after failure) -> every new family needs a `RECIPES` entry and ~8-10 `core` sfx per era (6.5 KB deflated each).
- **Licences**: CC BY needs attribution lines in the in-game Credits (auto from CREDITS.md; list grows from 124 to about 300 items, markdown 18 KB -> about 45 KB, fine for `_md.js`); CC BY-SA/GPL/NC rejected by `oga.py/fetch_oga.py`; `engine-loop-heavy-vehicletank` is dual CC BY 3.0/GPL (take CC BY); `tesla-coil...` has 5 licences (CC BY 4.0 ok); Commons returns HTTP 429 (probe today) and needs Retry-After backoff (scripted); the 194 MB firearm 7z takes a while and needs py7zr (present).
- **Dead cues**: `ui_select`/`ui_drop` (10 sites) silent today; 15 ledger rows unused; header comments say 113 families (116); `docs/audio_coverage.md` is generated and tested, regenerate after every cue change.
- **Nobody has listened** (verification_report): loudness balance and music choice for the new eras are unverified by ear; only ffmpeg metrics exist.
- **Text risk**: `createAnnouncer` mutates template objects (`l.tokens`), shares session memory across battles; swapping templates per era must reuse one announcer or call `setStats`; `tests/humor/announcer.test.mjs` pins the ancient category list (`SPEC_CATS`, line 17: >= 3 lines each) and quotas (>= 90 lines, >= 120 slotted templates), so a per-era template pack needs its own test list.
