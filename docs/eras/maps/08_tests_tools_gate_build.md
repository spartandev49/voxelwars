Method: read every named tool, ran the pieces (4 CPUs, Node 22.22, Chromium 1194 + SwiftShader), esbuild metafile for sizes, grep for coupling. ## 1. What this subsystem does today

1. **Gate** = `tools/gate.mjs` (36 lines), one sequential `spawnSync` loop. Flags: `--fast`, `--only=<substr>` (nothing else: no era, jobs, cache, steps, dist dir). Order: lint -> syntax -> every `tests/**/*.test.mjs` (sorted, 103 files) -> contracts -> build -> (full only) smoke standalone, smoke artifact fragment, tour, flow, modes. `--fast` skips test paths matching `/slow|fuzz|balance/` (10 files; no test has "balance" in its path) and the 5 browser steps, but still runs contracts + build. `--only` runs lint + syntax + matching tests and NOTHING else (no contracts, no build). Step timeouts: 300 s default, 600 s tests and smoke, 900 s tour/flow, 1200 s modes. Prints `PASS/FAIL name (secs)` (syntax prints none), tails 25 lines of a failing step, ends `GATE PASSED|FAILED (n)`. No summary table, no timing history, no cache.
2. **Measured gate** (this box): lint 0.16 s; syntax 8.9 s (315 `node --check` spawns, ~28 ms each, plus module retry); tests fast 93 files = 309 s; tests slow 10 files = 743 s; contracts 0.7 s; build ~1.2 s (estimated from the same code path: esbuild 0.26 s unminified / 0.17 s minified, deflate-9 + base64 0.32 s, gen-registry spawn; build.mjs itself was not run because it writes the shared dist/); smoke 31 s + 35 s; tour 35 s; flow 51 s; modes 227 s. **Fast gate ~320 s (5.3 min); full gate ~1,440 s (24 min).** CPU use is 1 core for ~75% of the wall time (sequential), browser steps use 2-3 cores (SwiftShader).
3. **lint** (`tools/lint.mjs`, 44 lines): 10 line regex rules over the 312 `src/` files only (not tools/, tests/). `PURE` prefixes include `src/content/` so every future `src/content/era_*` dir is automatically pure (no window/document/navigator/localStorage/AudioContext/requestAnimationFrame identifiers, no THREE, no `Math.random` in sim/content). 2 hard-coded browser adapters. `dilution` rule is case-insensitive and also scans comments/strings: `todo|fixme|xxx|lorem ipsum|coming soon|your-key-here`. No `lint-allow` is used anywhere in src today.
4. **contracts** (`tools/contracts.mjs`, 90 lines, 0.7 s): imports everything from `era_ancient`. Checks per unit: cost/hp/speed/radius > 0, text blurb/lore/codexJoke >= 6 chars, >= 3 deaths, >= 2 taunts, model builds via `content.modelFor`, <= 48 parts, abilities exist in the registry; roster **must be exactly 43**; every arena preset has a known recipe, name/blurb/tactics; every RECIPE generates a small arena with zones A/B and only catalog prop types; mutator ids agree sim/text/content; achievements unique + `test()`; every manifest sfx/music file exists; 3 docs exist. Fallback models are "soft" (fail only with `--strict`; the gate does NOT pass it). **It does not check** clips, sounds per unit, missions, puzzles, banned words, humour limits, audio-cue coverage: verification Q1 promises "UnitDef/Blueprint/Clip/Arena/Mission/cues" but those live in tests (`validateMission` in `src/content/era_ancient/campaign_validate.js` is only called by tests/campaign; clip coverage = tests/anim/roster.test.mjs; text = tests/humor/text.test.mjs; cue families = tests/audio/{cues,coverage,assets}.test.mjs). **No test or tool checks that a given unit has sounds** (routing is by `SPECIES_BY_ID`/role/ability tables in `src/audio/cues.js:180,238`; an unmapped ability is silently mute).
5. **Humour/safety rules** (`tests/humor/text.test.mjs`, 218 lines): per unit blurb <= 14 words, lore <= 35, deaths/taunts >= 3/2 and <= 12 words, unique; announcer lines <= 22 words, snake ids, 3 voices, ALL-CAPS tell for Brutus >= 85%, orphan followers; H4 banned-term sweep over 13 explicitly imported humor/campaign modules (> 2,000 strings): slurs (rot13 list), STEREOTYPE (savage, primitive, barbaric, pagan, heathen, **crusade, crusader**, terrorist, jihad...), RELIGION (**church, pope, bible**, christ, mosque, rabbi, amen...). No list of real nations/wars/extremist groups although e.md section 2 item 6 forbids them in copy; no era awareness.
6. **Balance harness** (`tools/balance.mjs`, 811 lines + `tools/lib/harness.mjs` 128): worker_threads pool (default `min(4, cpus)` workers; header says use `--workers=12`), one job type per section, results merged section by section into `docs/balance_data.json` (90.5 KB: keys duels, pairs, tune, escort, comp, fuzz, fun, diff, mirror, soldier, metrics, perf, meta) and `docs/balance_report.md` (245 lines) regenerated every run. Sections run **sequentially** (pool drains between sections). Deterministic (seeded; only `perf` is wall-clock/thread-CPU, run alone after the workers stop). "Bots" = `armygen` styles (balanced, rush, ranged, elite, chaos, counter) x difficulty tiers (easy/normal/hard behaviour) vs a fixed reference counter bot. A battle = `buildWorld` on `getArena(recipe,size,seed)` (default marathon medium seed 5), timeLimit 360, up to 366 sim-s, ~0.33 s CPU and ~43 sim-s per 2,000-dr pair battle (measured, 39 battles). Bands are literals inside `verdicts()` (:583-655), NOT data (table in section 2E). `tune`/`applytune` is an auto-tuner that rewrites unit lines of `src/content/era_ancient/stats.js` by regex.
7. **Campaign bots** (tests/campaign/_lib.mjs 160 lines, run_feasibility.mjs 89, feasibility.test.mjs 65, feasibility.slow.test.mjs 19): bots counter (authored `mission.reference` or generated counter-pick), greedy (chaos style, everyone advances), turtle (hold; on hold_hill forms on the hill), plus star hunters thrifty/melee/raid/expert (god-power play `installPowers` = meteor + zeus_lightning). 536 stored battles in `tests/campaign/feasibility.json` (11.7 KB, hash per mission via `missionHash`, `sim` fingerprint via `simHash()` over src/sim + src/world + **era_ancient/stats.js only**); fast test checks stored rates vs `mission.bots` bands (campaign.js:196 defaults counter .6-1, greedy .25-.7, turtle .1-.6; exceptions carry `botsWhy`), replays missions 1 and 8; slow test re-fights 6 seeds x (counter, greedy) x 9 missions = 108 battles = 135 s. Full re-measure = `run_feasibility.mjs` one process per (mission, bot).
8. **Build** (`tools/build.mjs`, 123 lines): runs gen-registry, esbuild iife (entry `src/app/main.js`, target chrome100/firefox100/safari15, `--minify` optional, `three` import forbidden, `define __VW_VERSION__ (package.json) __VW_BUILD__`), concatenates 7 CSS files (silently skips missing), reads `assets/manifest.json` (sfx + music only -> 382 files; vfx skipped), embeds the 28 `core` audio entries as base64, the manifest (241 KB), CREDITS.md, `assets/anim/humanoid_clips.json` (340 KB) as `window.__VW_*` globals, deflate-raw level 9 + base64 into `<script type=text/plain id=vw-pack>` (fragment, `DecompressionStream` loader) and a plain standalone html; writes `dist/voxelwars.html`, `dist/artifact/index.html`, `dist/artifact/files.json` ({path: path}, 382 entries; COORD feeds it to the Artifact tool `files` map by hand, today 2 calls of <= 255); CSP allowlist lint on src/href + CSS url(). Prints `built v1.0.0: html KB, js KB, css KB, N asset files KB`. **There is no size budget check, no file-count check, no per-family report, no `--report`/`--out` option** (usage mentions `--no-sourcemap`, which no code reads). The gate builds **unminified** (fragment 3,312,977 B); publishing uses `--minify` (3,106,540 B).
9. **gen-registry** (`tools/gen-registry.mjs`, 53 lines): writes 3 git-tracked files in `src/_generated/` (registry.content.js 209 lines, registry.ui.js 95, registry.optional.js 53). Content groups are globbed from the hard-coded `A='src/content/era_ancient'`: UNIT_MODEL_MODULES 3, PART_MODULES 19, BEAST_MODULES 13, PROP_MODEL_MODULES 7, HUMOR_MODULES 12 (files starting with `_` skipped, non-recursive), CLIP_MODULES 13, ABILITY_MODULES 30; UI groups SCREEN 23, HUD 18, EDITOR 3; 26 OPTIONAL single modules (9 point into era_ancient: blueprints, campaign, survival, puzzles, daily, custom, humor/announcer, humor/ui_text, props/models/index). Missing optional -> exported `null`. `VW_SKIP=a,b` env skips paths. Consumers: `src/app/{main,game,router}.js`, `era_ancient/content.js`.
10. **Browser tools** (smoke 71, tour 53, flow 73, modes 251, look 63, perf 57 lines) each duplicate ~20 lines (CSP string, wrap(), route to `.cache/cdn/three.min.js`, hard-coded `/opt/pw-browsers/chromium-1194`), all take `--page=` (default `dist/voxelwars.html`; smoke/tour/flow/modes do `path.join(root, page)` so an out-of-tree page needs `../../../tmp/...`). All fail on any console error/warning, pageerror, CSP violation or HTTP >= 400. `smoke --battle=6` is a boot/placement/countdown test: it reached **tick 7 (standalone) / 15 (fragment)** at 4x in 6-7 s of SwiftShader, so it does not exercise combat, projectiles or deaths. `flow` clicks Quick Battle -> Skirmish -> Quick Fight -> FIGHT, fast-forwards with `world.step(90)` slices until `ended`, results, Rematch. `modes` default sections: campaign, suggest, missions, puzzle, survival, daily, nav, camera, myarena (+ `timing` opt-in).
11. **modes per section (shot mtimes)**: campaign mission 1 ~20 s, suggest ~8, missions (9 + 6 puzzles, deploy + 20 sim-s each) ~57 (3.8 s each), puzzle ~10, survival ~12, nav ~30, camera ~65 (14 x 4 s real sleeps), myarena ~10, daily ~10.
12. **Tests**: 103 `*.test.mjs` (93 fast) + 61 helper/shot/fixture files, 14.0 k lines; plain `node:assert` with `tests/sim/_util.mjs` `test/finish`, run as separate `node` processes, one at a time. None write files or open ports (browser tests intercept routes), so they are parallel-safe; 4 time with `performance.now()` and must stay in a serial lane (anim/perf, audio/browser, audio/synth, ui_battle/hud; sim/perf uses thread CPU time with 2.5x slack, so it is robust). 65 files under tests/ and 13 under tools/ import `era_ancient` (121 files in src+tools+tests per e.md: src 43, tools 13, tests 65).

## 5. GAPS for the new eras (what cannot be expressed today, smallest viable extension)
- **No era scoping anywhere** (gate, contracts, tests, browser tools, balance, feasibility, build). Smallest: registry-driven `ERA_IDS` + env `VW_ERA` + `--era=` flags (seams 1, 5, 11-15, 18, 20, 21); default `all` for COORD, one era for an era team.
- **Per-unit coverage matrix is not a gate step.** Add to contracts (cheap, < 3 s per era): for every unit of the era: model builds, not fallback, <= 48 parts, tint floor by rig; every clip id the sim can publish (`meleeClip/rangedClip` + the 15 base clips of anim/roster.test.mjs) resolves for its rig; text limits (blurb/lore/deaths/taunts/codexJoke + moment keys); a **sound row**: `species`/role/weapon/projectile kind and each ability map to existing cue families (`CUES` in cues.js) and each family resolves to a real asset or a justified synth (`SYNTH_REASONS`); stats sane; abilities registered; tags/role in the role vocabulary. Print the matrix (unit x model|clips|text|sound|tint) so QA can read it.
- **Mission/puzzle/arena/prop validators are not in contracts.** Call `validateMission` for every mission/puzzle of every era, `generateArena` for every recipe x 3 sizes (as tests/props/arenas does), prop models for 3 stages, `PROP_CATALOG` vs `LIMITS.propTypes`.
- **New mechanics have no balance scenario type.** `battle(j)` takes groups/placements, `hold`, `rules`, arena recipe; it cannot place props/cover/mines, script a timed orbital strike, or assert "mechanic exercised". Smallest: `j.props`, `j.script:[{t,kind,x,z}]` (reusing the mission `script.events` of map 06) and a `COUNTERS` table (data like `DUELS`) for the e.md 5 counters: pike > knight > archer, armour > rifle, rocket > armour, sniper > officer, helicopter > tank, anti-air > helicopter, EMP > mech, shield > laser chip, cloak > range. - **New roles are invisible to the harness**: `TUNE_ROLES` (8 roles), `BOSS` rule (tag boss or role monster), escort `alone` roles (support/hero/siege), `S.roleEfficiency(role)` (U8 caps), `analysePairs` field filter (role 'support') -> add vehicle/air/artillery/etc. explicitly or judge them like siege (30% of an army with an escort), otherwise helicopters/tanks are judged as lone units in an open field.
- **Anchors and gag lists are Ancient literals** (hoplite = 100 for U7 and the escort, 10 Ancient gag events for S23 "chaos gag >= 60%"): per-era `ANCHOR`, `GAGS`, `DESIGN_COSTS`; S23 gag band only if the era defines >= 3 gags.
- **No real-world-content check** in the text sweep, and the banned list collides with natural Medieval vocabulary (seam 22).
- **Smoke does not fight** (tick 7/15) and runs only Ancient; **tour/flow/modes cannot reach an era** (seams 11-14).

## 6. RISKS (numbers)
1. **Ancient baseline drift (O4)**: `faction:'mixed'` (27 test/tool sites + 24 src files), `buildSimDefs()` merged table, `DEFS` in the harness (24 test files) change as soon as defs merge; armygen draws by sorted ids + RNG so any pool change reshuffles every army and every recorded number (balance_data.json, perf, feasibility.json hashes, 536 stored battles, golden S1 hashes). Mitigation: record golden master BEFORE the registry refactor (stateHash after 600 ticks for ~10 mixed/pair/mission battles, `DEFS` JSON hash, `balance pairs` matrix at --quick) in `tests/fixtures/ancient_golden.json`; the refactor must reproduce them bit-for-bit.
2. **Packed size**: 3,106,540 B minified / 3,312,977 unminified vs 5,000,000. Core audio base64 is 60% and incompressible. An Ancient-sized era pack costs ~270 KB b64; x3 = +810 KB, engine/UI growth ~+100 KB, manifest rows +70-100 KB, optional new core fallbacks (gun/laser/mech, ~40-60 KB mp3 each, b64 +33%) -> **4.1-4.3 MB minified, 4.4-4.6 MB unminified**: margin 0.4-0.9 MB. Levers if needed: re-encode core pack 64->48 kbps (-25% = -470 KB b64), drop core entries now covered by synth, shorten humour tables. Single IIFE bundle (CSP forbids splitting, no dynamic import), so all eras always ship.
3. **File-count cap**: 382 published files now; one publish <= 255 files and 64 MB, a version <= 511 files and 256 MB (Artifact tool contract of this session; docs/verification.md B10 says 255/40 MB). The page is one more. **Only ~128 files remain for three eras** (~42 each) vs Ancient's 382; at Ancient density (374 sfx + 8 music) three eras would need ~1,150 files. Need: shared families across eras + audio banks (concatenate a category into one mp3 with an offset table in the manifest; `SfxBank` already loads lazily by group) or fewer clips per family. Bytes are fine (10.98 MB of 256).
4. **Gate time and CPU contention**: observed load 4-6 from other agents while measuring; 3 era teams + COORD will contend for 4 CPUs; lanes help only if jobs <= cpus-1; Chromium steps are memory-hungry (SwiftShader ~300% CPU for one page). Timing-sensitive tests (4) must stay serial; `perf.test` thresholds have 2.5x slack on thread-CPU, OK.
5. **Balance runtime**: Ancient 41 min loaded / ~25 idle; per era ~33 min loaded, ~19 with reduced samples (estimate scaled from the recorded seconds); new mechanics (projectile kinds, beams, suppression fields, mines) may raise per-battle CPU from ~0.33 s (measured) - a 2x slowdown doubles every number. Cross-era sections would explode (22 k battles).
6. **Determinism/perf budgets**: S1 hashes, 300 units <= 2 ms/tick thread CPU (measured 1.09 ms at 308, 1.62 ms at 535), 600 units on Marble <= 160 draws and 1.2-2.0 M tris (smoke: 115-130 draws, 358-382 k tris at 42 units). Mechs/tanks/helicopters are triangle-heavy: perf must be run on the heaviest composition per era, not on `autoFill`.
7. **Save compat**: only v1 fixtures; no real v2 blob of the released build; `ARENA_SET`/`MISSION_IDS` gates in `src/save/stats.js` (map 06). A republish with a changed save shape loses stars silently ("Ancient save must not lose anything"): the golden blob + id ledger (seam 24) are the guard.
8. **Silent fallbacks that hide missing era content**: armygen pool fallback to all defs, CSS `.filter(exists)`, optional registry modules exported as `null`, `missionLine` generic copy (map 06), contracts soft findings (fallback model), unmapped ability cue -> mute. Make each a hard error for registered eras.
9. **Chromium and tooling**: `/opt/pw-browsers/chromium-1194` hard-coded in 28 files (tools and tests); `playwright-core` + `esbuild` only; browser tools wait 60-90 s for `data-vw-ready`; boot grows with models built from code at run time (3 eras of builders). Smoke/tour ran 0 console lines today; any new three.js r128 deprecation (e.g. new material features) fails the whole gate.
10. **Lint/test traps in era copy**: `todo|xxx|fixme|coming soon` anywhere; identifiers `window/document/navigator`; banned words (crusade, church, pope, pagan, savage, primitive, terrorist...) - the Medieval and Modern writers will hit them.
11. **Campaign records**: any mission data change invalidates its `missionHash` and fails the fast test until `run_feasibility` is re-run (~1.25 s/battle measured in feasibility.slow, 108 battles in 135 s: 450 band battles per era = ~9.5 min on 1 CPU, ~2.5 min on 4 processes; all 536 incl. star hunters ~11 min); `feasibility.json` per era; 20 seeds give ~10 points of error (verification report).
