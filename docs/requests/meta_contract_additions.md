# META -> COORD: additions to docs/app_contract.md (please fold them in; all are implemented and tested)

**Game** (src/app/game.js, thin delegations to `src/app/meta.js`; every one is safe when the world is null)
- `aim(powerId|null) -> bool`: god-power target mode. Arms a ready power (toast + false when the fight has not started, powers are off or it is on cooldown); the next click on the terrain casts there through `cast()` and disarms (`Game.pointerDown` routes it, before selection); `aim(null)` / Esc (HUD) / a right-click (main.js) cancel. A ring (render-only group, `renderOrder 22`) follows the cursor. Emits `'aim' {id|null}`.
- `possessInput(patch)`: Take Command from the touch HUD, `patch = {move:{x,y} (screen space, y < 0 = forward), attack?, ability?: 1..3, sprint?}` -> tick-stamped `possess` commands, camera-relative (rig.syaw), merged with `sendPossess` (keyboard) so the two never fight. See docs/requests/meta_possess_sprint.md.
- `teachingNext()`, `skipTeaching()`: mission-1 teaching beats (`TEACHING_BEATS`); steps advance on the player's actions (placing >= 6 soldiers, casting a god power) or "Got it"; skip / finish persist `vw.seen.teaching` and `settings.seenHints.teaching`.
- `killcam() -> Promise<bool>`, `killcamActive()`, `killcamStop()`: 4 s of 0.25x real-time dolly on the final kill (a hero kill from the last 8 s wins), then camera, speed and pause are restored; results are never touched.
- `meta` (set by main.js: `game.meta = createMeta(...)`): `Game.begin` calls `meta.attach(world, setup)` (never for the title diorama), `dispose` calls `detach()`, `frame` calls `meta.onFrame(dt)`, `hud()` / `results()` call `decorateHud` / `decorateResults`, `_feed` yields to the meta kill feed. `godPowers()` now passes the player team to `GodPowers.list(team)` (it was called without a team, so every cooldown read NaN).
- `results()` no longer calls `LESSONS.generateLessons(world)`: `sim/lessons.js` takes an event LOG (`[type, payload, t]`), not the World, so that call threw on battle_end.

**Game events**: `'announce'` (the announcer line, same shape as `HudData.announcer`), `'aim' {id}`, plus the existing `'toast'` for achievement unlocks (`{text:'Achievement unlocked: <name>', kind:'success'}`, spaced 2 s apart).

**HudData** adds `possess {id,name,hp,hpMax,abilities:[{id,name,key,cd,cdMax,ready}]}|null`, `teaching {id,index,total,title,text,target?,who,canSkip,ack}|null`, `aim: powerId|null`; `announcer` and `killfeed` are now filled (killfeed rows `{t, team, verb, text, cause, killer|null, victim, srcDef, dstDef, key}`).

**ResultsData** adds `funnyStats [{label,value}]` (<= 4, labels from humor/results_text.js, values are strings), `lessons [{text,fix,who,id}]` (3), `mvp.quote` (the unit's last words), `summary` (the BattleSummary of docs/lifetime_stats.md §3: campaign can `Object.assign(summary, run.tracker.extras())`), `achievements [{id,name,desc,icon}]` unlocked by this battle, `survival {wave,waveName,score,kills,remainingCost,best (previous),rank,board}` for kind 'survival' (also written to `vw.survival`), `daily {date}` for kind 'daily' (the Daily screen records the history itself through `progress.set('daily', ...)`).

**ctx.save** (all in main.js): `progress, survival, daily, seen` (Doc: get(key?)/set/remove/all/reset; `progress.get('survival'|'daily'|'survivalBest'|'dailyLast')` read the sibling documents, `progress.reset()` wipes progress + survival + daily + lifetime stats), `stats` (LifetimeStats: `get()` live object, `totals()` copy; `zeusRagequits`/`zeusRageQuits`, `takeCommandKills`/`commandKills`, `bestWave` and the UI extras `deaths damage shieldBlocks arrows boulders unitsPlaced drachmaeSpent elephantTramples goatsSaved campaignStars dailyStreak`), `draft(editor)` -> `{load, save, clear, meta}` over `vw.draft.<arena|soldier|painter>`, `exportAll()`, `importAll()` (see meta_import_contract.md).

**Campaign hook**: `app.meta.recordCampaign(missionId, stars, completed?)` writes `progress.stars`, `stats.campaign`, and checks the campaign achievements; `app.meta.ui('arena_saved'|'soldier_saved'|'arena_played'|'campaign', payload)` for other UI events (collection `put()` already calls arena/soldier_saved).

**Store** (save/store.js): `getVersioned(key) -> {v,data}`, `getRaw/setRaw`, and quota handling that loses nothing: a refused write stays readable (`pending()`), status becomes 'full', `app/meta.js watchQuota` opens one modal (export / delete oldest), `flushPending()` writes the kept values once there is room.
