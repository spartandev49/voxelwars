# tools_hooks (TOOLS-VERIFY -> INTEGRATION, RENDER, COMEDY-EDITOR/SIM): dev-only hooks the verification tools need (VF open item OI-2)

Why: `tools/campaign_play.mjs` (VF 3.9), `tools/uiscan.mjs` (3.17), `tools/readability.mjs` (3.16), the slice kit (`spec/S-slice` SLW-02) and `release_check` (3.12) may only drive the real UI, so everything below is READ-ONLY or time-control and exists only when `window.__vw` exists (`installHook` in `src/app/main.js`). None of it changes a sim result, a save, a draw call or the production bundle's behaviour. Verified by grep on 2026-10-08: none of these exists today (`installHook` defines `game world engine state step goto seed quick fight version audio metrics clock`).

I (TOOLS-VERIFY) cannot edit `src/**`. Until each hook lands the corresponding tool step reports `SKIP hook missing: <name>` (a skipped criterion is UNVERIFIED, never green) and the tool keeps working through the fallbacks named per hook. Owners: the hot-file owner of the file named in the third column implements; TOOLS-VERIFY reviews against the acceptance line.
