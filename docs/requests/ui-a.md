## 1. COORD (app shell, router, save, game, diagnostics)

1. **`K.init(ctx)`**: main.js does not call it; every screen calls it on mount (idempotent), so it works, but two writers set `html{font-size}`: main.js (`16 x uiScale`, lines ~130/134) and `K.init` (`16 x uiScale x viewport fit`, 1 up to 1280x720, 1.3 at 1920x1080). Simplest: call `K.init(ctx)` once at boot and delete main.js's `uiScale` font-size and `vw-reduce-motion` class code (`K.applyUiSettings` does both, plus `.vw-high-contrast` and the colour-blind palette classes). Needs `settings.on(fn)` returning an unsubscribe (the real `Settings` does).
2. **Screen ids** my screens navigate to: `splash title quick placement settings credits diagnostics codex achievements stats phone_notice fatal` (mine); `campaign survival daily puzzles arena_builder workshop` are title/menu targets (UI-B / EDITORS; **`puzzles` is not mine**). Params I pass: `quick {arena}`, `placement {from:'quick', setup}`, `settings {tab}`, `codex {tab, unit}`, `phone_notice {editor}`. The title routes the editors to `phone_notice` when `ctx.platform.isPhone()`.
3. **Back/Esc contract (verified against router.js)**: `back()` calls `inst.onBack()` first; `true` = consumed (modal closed, sheet closed, rebinding cancelled), otherwise the router navigates. My screens never call `ctx.nav.back()` inside `onBack`. Modals (`K.modal`) take Esc in the capture phase on `document` and `stopPropagation`; skip Esc in any capture-phase listener while `K.hasModal()`.
4. Every screen api also has `exit(): Promise` (10 px fade-sink, instant under Reduce Motion); `await api.exit?.()` before removing the root if you want out-tweens, otherwise ignore it.
5. **Placement keys** are in `onKey(e)` (returns true when consumed): `brush` and `erase` read `settings.keys` (ids and defaults identical to `input.js DEFAULT_KEYS`; guarded by `tests/ui/keymap.test.mjs`), Ctrl/Cmd+Z/Y, Space focuses FIGHT, ?/H hints. Q/E stay with input.js.
6. **Game events used by placement**: `placement`, `brush`, and **`ghost {valid, reason}`** for the red cursor tooltip (shown only while the pointer is over the battlefield, hidden over panels). Request: add `code` next to `reason` in `_validity()` / the `ghost` event / the `toast` events (one of HUMOR `PLACEMENT_REASONS`: `enemyZone underwater blocked steep budget cap types lava outOfBounds`); I then show HUMOR's wording, else your `reason` text unchanged.
7. **Setup fields I add**: `armies.A|B.style` (`balanced|rush|ranged|elite|chaos|counter`), `armies.*.faction` may be `'mixed'`, `rules.formation`, `rules.timeLimit` (0/180/300 s), `rules.weather` null = arena default, `arena.env.time` only if the time slider moved, `arena.presetId` + `arena.seed`. Quick Fight = `newSetup('quick')` -> `begin` -> `tools.autoFill(0|1, {style, faction, budget})` -> `fight()`; it does not navigate (router moves on game state `countdown`).
8. **Scout** `info.scout(team)` real shape `{code, severity:'weak'|'tip', kind, text, counters:[ids], share}` is rendered; counter chips select that unit.
9. **Army presets** (placement): `tools.saveArmy(name)` returns BOTH teams and persists nothing; `tools.loadArmy(data)` is additive and unchecked. The screen therefore: keeps only the selected team's records, stores `{id,name,v:1,team,records,n,cost,saved}` in `ctx.save.armies` (cap `armies.cap`, oldest dropped with a toast), `clear(team)` before loading, refuses over budget / unit cap / 16 types with the numbers, and for the other team mirrors positions (`-x,-z`) and heading (same point reflection as the Mirror brush). Share codes: `encodeShare('army', {v:1,name,records})` / `importShare(text,'army',{defs})` from `save/share.js`. Suggestion: `loadArmy(data, {team, replace})` inside Game would let the screen drop the mirroring and the checks.
10. **Save layer** as used: `armies|soldiers|arenas.list/get/put/remove`, `status()` (`ok|full|memory`, polled), `store.flushPending()` ("Try saving again" when full), `progress.get('achievements')[id].at`, `progress.get('stars'|'codex'|'survivalBest'|'dailyLast')`, `progress.reset()` (progress doc only: arenas/soldiers/armies/settings stay), `stats.get()` (docs/lifetime_stats.md: nested `byDef`, `arenasPlayed`, `campaign`; alias twins shown once), `exportAll()` (code string; `platform.downloads` is null, so Export shows a copyable text box), `importAll()` (resolve `{ok,warnings,...}` / reject with the first reason; warnings are toasted).
11. **Diagnostics**: your FLAT snapshot is normalised into Overview / Graphics / Performance / Audio (path tally + collapsed per-asset list + `failedAssets`) / Storage / CSP / Errors / Log (`ctx.diag.log`, `t` in ms); an already-sectioned snapshot still works. Copy puts the raw snapshot + log tail on the clipboard.
12. **Fatal panel**: `renderFatal(host, {kind:'webgl2'|'cdn'|'unknown', cause?, message?, diagnostics?, onSafeMode?, onReload?})` needs no ctx and carries HUMOR's titles/bodies/jokes. `boot.js showFatal` could delegate to it (one panel, one copy source). Default safe mode sets `localStorage['vw.safe']='1'` + reload (matches `boot.js safeMode()`).
13. **Settings**: quality preset also writes `shadows/bloom/clouds/resScale`; Gameplay now has the Cinematics toggles `choreoIntro choreoFinish choreoOrbit` (default on) and `cinematicStart`; `settings.get('vol.master')` dot paths work with the real Settings. Reduce motion / high contrast / palette / UI size apply instantly through `K.applyUiSettings`.
14. **CSS order** (build.mjs): boot.css, kit.css, screens.css, hud.css, editors.css.
15. **`src/_generated/registry.optional.js` imports `src/ui/mockctx.js`** (a test helper) into the production bundle; it also pulls the real content modules a second time. Please exclude MOCK from the shipped registry.
16. **`ctx.content.arenaThumb(id)` returns a Promise**: every screen goes through `setThumb(img, ctx, id, placeholderEl)` / `showThumb` (`screens/_shared.js`): placeholder gradient (`.vw-thumb-ph`) until it resolves, stale results ignored. The mock now returns a Promise too; `tests/ui/thumbs.test.mjs` fails on any raw `img.src = promise`. `tools/tour.mjs --screens=title,quick,survival,daily,codex,settings` passes.
17. In UI-B's files I changed only the thumbnail lines (`survival.js` ~132, `daily.js` ~53) plus an import of `./_shared.js`; UI-B please keep them.
