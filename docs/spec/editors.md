# spec/editors.md — Arena Builder, Soldier Workshop, Voxel Painter (owner EDITORS; follows spec/ui.md kit)

Tablet+ only (>= 768 px wide, pointer or touch). Phones see the friendly notice. All editors: undo/redo (Ctrl/Cmd+Z, Shift+Z, buttons, 100 steps, delta-compressed), autosave draft every 20 s (key `vw.draft.*`), explicit Save with name, export/import share code, validators with fix-it messages, keyboard shortcuts overlay (`?`), tooltips with the real shortcut, and sounds.

## 1. Arena Builder
Layout: 3D viewport (orbit camera as in battle, top-down toggle) centre; left toolbar; right inspector; bottom bar (size, name, Save, Share, Playtest, Undo/Redo).
Tools (each with radius 1-20 u, strength, shape circle/square, falloff, hotkey):
1. **Raise/Lower** (LMB raise, Shift lower), 2. **Smooth**, 3. **Flatten** (click sets target height, drag flattens; alt-click samples), 4. **Paint material** (16 materials; "paint under water" ok), 5. **Water/Lava level** slider (+ lava toggle), 6. **Noise** brush (adds seeded fbm), 7. **Ramp/Road** line tool between two points (cuts a walkable ramp, paints cobble), 8. **Stamp** presets (hill, crater, mesa, trench, island, ridge), 9. **Props** (catalog by category with search, rotate R, scale mousewheel+Alt, Shift scatter brush with density, delete tool, snap to cell, mirror about arena axes), 10. **Hazards** (quicksand, spikes, fire pit, boulders lane, geyser, lava) as radius circles, 11. **Zones** (drag A/B rectangles; must fit and not overlap; shown as translucent blue/red overlays), 12. **Symmetry** (off / mirror X / mirror Z / rotate 180°) applying to terrain, paint and props, 13. **Generate** (recipe dropdown + seed + "Reroll" + "Apply to terrain only / props only / both"), 14. **Environment** (time slider 0-24 with live sun/sky, weather, fog, wind, theme music mood), 15. **Info** (name, author, description, tags).
Size: small/medium/large (resizing resamples the map; asks via in-page modal if content would be lost).
Validators (shown in a panel with "Fix" buttons): both zones exist, inside bounds, not overlapping, >= 30 walkable cells each, NOT underwater (fix: raise), a path exists between zone A and zone B on the nav grid with unit radius (flood-fill; fix: "carve a ramp"), props count <= 1500 and unique prop types <= 40, hazards <= 60, name 1-32 chars. Save is allowed with warnings; Playtest is blocked only by blocking errors.
**Playtest** button: opens quick setup with this arena preselected and returns to the editor with state intact (not re-generated).
Library ("My Arenas" + presets): thumbnails (<= 6 KB jpeg-ish data URL rendered from the viewport), rename, duplicate, delete (in-page confirm modal), export code, import code (paste box, strict validation errors in plain English).

## 2. Soldier Workshop
Layout: left = category tabs and part pickers; centre = 3D turntable (drag orbit, zoom, clip picker idle/walk/attack/block/death, weapon swing preview, scale reference with a hoplite ghost toggle); right = tabs Stats / Abilities / Colours / Personality / Voxel Paint; bottom = name, cost, Save to roster, Use in battle, Share, Randomise, Reset.
Parts (all have ids in `content/parts/*`; locked silly parts show a lock with the unlock hint):
- Body: slim / average / stocky + height slider 0.9-1.2 (cost impact), skin swatches (8 human + green, blue, stone, gold, ghost), hair style (12) + colour.
- Head: helm (>= 18: none, laurel, Corinthian, Attic, Phrygian, Chalcidian, Galea, Montefortino, Centurion crest, Nemes, Pschent, Khepresh, Persian tiara, Persian cap, Gallic winged, horned, wolf hood, boar helm, bull head, jackal head, cyclops head, snake hair, + silly: colander, traffic cone, pot, straw hat), face (stubble, beard short/long/braided/pointy, moustache (huge), eyepatch, warpaint), eyes colour.
- Torso: tunic/chiton, thorax (muscle cuirass), lorica segmentata, scale mail, chainmail, leather, linen kilt, toga, fur pelt, robe, bandages, bare + warpaint; Shoulders: none, pauldrons, lion mantle, scarf; Legs: bare, greaves, pteruges, trousers, wraps, shorts; Cape (none/short/long/tattered); Back (none/quiver/banner/backpack/wings(unlock)/sun disc).
- Main hand (>= 18): dory, short spear, sarissa, xiphos, gladius, spatha, khopesh, axe, double axe, mace, club, hammer, trident, javelin, bow, composite bow, sling, staff, scepter, torch, + silly: fish, rubber chicken, baguette, frying pan, scroll of doom, olive branch, foam finger. Off-hand (>= 9): hoplon, scutum, wicker, hide shield, round shield, buckler, torch, second sword, none.
- Colours: primary, secondary, trim, metal (bronze/iron/gold/silver/steel/blackiron), cloth, emblem (10).
Stats (point-buy, 100 points; per-stat caps and diminishing returns): HP, Damage, Attack speed, Speed, Armor, Range (derived from weapon, adds only through weapon choice), Morale. Weapon class sets role and base: melee/spear/pike/ranged/thrown/magic. **Cost** = `costFormula(stats, weapon, abilities)` from `sim/stats.js`, clamped so that no combination exceeds 1.35x the cost-efficiency of the best shipped unit of the same role (checked by the fuzzer). Total cost shown live with a "Power rating" radar.
Abilities: pick up to 2 from the class list legal for the weapon/body class (e.g. `kick` needs melee, `heal_pulse` needs staff/scepter, `rage` any melee) with cost impact. AI style: charge / hold / skirmish / flank / guard / support.
Personality: name (random funny name generator button: "Sir Chadius the Mildly Concerned"), catchphrase on spawn (<= 40 chars), 3 death quotes (<= 40 chars each, defaults generated), voice pitch.
Roster: "My Soldiers" (up to 24), duplicate/edit/delete, thumbnail; custom soldiers appear in the placement palette under "My Soldiers"; max 16 distinct types per battle includes them.
Hard guards: size/reach limits (weapon reach <= 3.6 u, scale 0.85-1.35 for custom soldiers (no giants)), collider derived from the compiled model bounds with caps (radius 0.3-0.7), nav radius capped; imported blueprints re-validated and re-costed (cost is never trusted from the file).

## 3. Voxel Painter (opens from the Workshop "Voxel Paint" tab)
Edits one part at a time (head, crest, body, armUL..., weapon, offhand, back, cape...) on its **fixed canonical grid** (see spec.md §3.1). Views: 3D (orbit, click to paint on faces with a hover cursor), 2D **slice** view (layer slider along any axis, click/drag to paint, large pixels, grid, onion-skin of adjacent layers), with a mini preview of the whole soldier wearing the edit (live, animated optional).
Tools: pencil (add voxel on face), eraser, paint (recolour existing), fill (flood 3D / layer), line, box (filled/hollow), eyedropper (alt/long-press), select+move (box), mirror X/Y/Z toggles (X defaults on for symmetric parts), brush size 1-3, undo/redo, clear part, reset to generated, copy/paste part to opposite side (flip), rotate/flip selection. Palette: 24 default swatches + HSV picker + recent colours + hex input + "team tint" and "glow" flags as material toggles; import/export palette as a share string. Painted voxels are stored in `bp.paint[partId]` as RLE; a "voxel budget" per part prevents absurd volumes (cap per part e.g. 1500).
Touch: tool buttons large; two-finger orbit/zoom in 3D; slice view recommended on touch (default on touch devices); pointer-event driven; Playwright tests synthesise pointer sequences for paint/erase/fill/mirror/undo.

## 4. Share codes UI
Export: shows code length, copy button (clipboard with fallback to a selectable textarea), "Download" via `downloads.save` when available, QR not needed. Import: paste box, button, strict validation with plain-English errors ("This code is for an arena, but you are importing a soldier", "Unknown prop 'dragon_egg' — the code may come from a newer game version", "Too long: 61,203 > 60,000 characters"), preview before accepting. Round-trip fuzz tests in `tests/save/`.
